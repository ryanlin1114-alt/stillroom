# STILLROOM v3 — 靜室

繁體中文、捲動式心理恐怖單頁網站。七個場景：窗簾、第四扇門、安全監測、牆內輪廓、無盡走廊、牆後住客、最後空房間。

## 使用
直接開啟 `index.html`。所有視覺場景以內嵌 SVG 製作，不依賴外部圖片；字體使用 Google Fonts，離線時會回退至系統字體。

## GitHub Pages 更新
1. 前往既有 `stillroom` 儲存庫。
2. 將此版 `index.html` 內容取代儲存庫根目錄的舊 `index.html`（可在 GitHub 開啟該檔案，按鉛筆圖示進入編輯，貼上新內容並 Commit）。
3. 若 GitHub 的網頁上傳支援覆蓋同名檔案，也可直接上傳此 `index.html`。
4. 等待 Pages 自動部署；網址不變。

## 說明
- 本版為**單檔網站**，舊版的 `style.css` 和 `script.js` 不再被引用，可保留但不會影響。
- 不使用攝影機、麥克風、地理位置或訪客個資。
- 動畫依照捲動位置推進，手機及桌面可用。
- 為避免閃爍風險，沒有頻繁閃光或突然跳臉。
